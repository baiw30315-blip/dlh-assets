# 大凉龙虎传 RPG v4.2 · 记忆与存储整合测试版

2026-11-03

## 下载与导入

下载本目录的 `DLH-RPG-v4.2-memory-20261103.png` 或同名 JSON，任选一种导入酒馆。PNG 内嵌角色卡与 JSON 内容相同。

本版运行标识为 `4.2-local.20261103-memory`。这是包含完整世界书和配套脚本的整合测试版，脚本随卡提供，远程自动更新关闭。

保留酒馆原有插件环境。随卡脚本按默认设置使用，只需原 MVU 与悬浮球加载器处于启用状态，其余模块由加载器统一启动，无需逐项开启。原 MVU 与其他插件仍有各自依赖，本版不等于整套酒馆可完全断网安装。

## 本版内容

- 武墓跨聊天武学、体质定义库；相同定义去重、同名多版管理，成长进度各存档独立。
- 更新后的菜单图标，以及气海圆满门槛、非伏击判定、战后下一楼重 Roll 等修复。
- 事实记录、相关记忆召回与轻量剧情调度。
- 锻造、炼丹按批次简短承接正文，保留必要的物品结果信息。
- 正文状态视图裁剪与历史记录整理。
- 单人聊天保存文件对重复内容进行复用，读取时恢复完整数据；标准 JSONL 导出在本模块启用时展开为完整格式。

武墓全库保存在本机独立数据库，只把当前存档实际使用的定义带入存档。文件复用减少重复存储，实际缩减幅度随存档而变；它不代表正文 Token 或运行内存按同比例下降。

## 使用提示

升级试玩前请备份原角色卡与聊天。标准导出聊天时保持本版脚本启用，便于得到已经展开的完整 JSONL；直接从服务器复制的原始聊天文件可能包含本版的便携格式，需要配套运行包读取。新设备使用武墓时，请通过武墓导出、导入迁移定义库。

本版已完成封包与隔离浏览器检查，真实酒馆、模型与实体手机的完整验收仍需试玩反馈。已知完整世界书的隔离检查存在「剧情线/雷谱之争 · 第三折」缺叶问题，尚未修复。后续进一步的提前渲染、长档按需裁剪与发送链统计尚未加入本版。

反馈时请附运行版本、操作步骤及第一条错误信息。
